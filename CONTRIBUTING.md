# Contributing to ymir

First off, thanks for checking out **ymir**! 🚀

Right now, `ymir` is a solo passion project that I'm hacking on in my free time just for fun and exploration. Because of that, **I’m not actively looking for code contributions or pull requests** at the moment. 

### Found a Bug or Want to Chat?
Even though I'm keeping code contributions closed for now, bug reports, edge cases, and general feedback are always appreciated! 

* Head over to the **[Discord Server](https://discord.gg/uhNJb7ShQ5)** to report issues, talk about Wayland, or just hang out.

Thanks for stopping by and for understanding!
