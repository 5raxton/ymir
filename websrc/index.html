Windows that scroll,
tiling that breathes.

ymir is a scrollable-tiling Wayland compositor written in Rust on top of Smithay. Your windows live in columns across an infinite strip — opening a new window never resizes the ones you already have.

Get started View source
$ ymir

Two layouts, one strip

Every column is scrollable tiling at heart. Flip any column into Dwindle at runtime and watch new windows binary-split the focused window, taking exactly half its space.

Scrollable tiling

Stack windows up and down in each column. The strip scrolls right to reach more columns — nothing ever resizes to make room.

Dwindle

Each new window splits the focused one into a resizable binary tree. Gradient borders make the tree visible at a glance.

Everything a modern desktop needs

Not just a window manager — a full Wayland compositor with the protocols, polish, and integrations you'd expect.

◧ Dynamic workspaces

GNOME-style vertical workspaces that remember their output and migrate back when a monitor reconnects.

▦ Modern rendering

OpenGL ES with VBlank-synced damage redraws, blur, gradient borders, drop shadows, and rounded corners.

☾ Lua configuration

Everything lives in ~/.config/ymir/init.lua — includes, live-reloading, and an imperative ymir.* prelude.

⬚ Floating & fullscreen

Floating windows, maximize, fullscreen, an overview zoom, and an MRU switcher with live previews.

⌨ Input, all of it

libinput for keyboard, mouse, touchpad, touchscreen, tablets, and trackpoints — plus grabs and gesture trackers.

♾ Multi-GPU

Primary render-device detection, dmabuf feedback, and texture copy between GPUs.

⎋ Screencasting & screenshots

Output and window casts through xdg-desktop-portal-gnome and PipeWire, plus built-in area screenshots.

◒ Accessibility

Full screen-reader support via accesskit and AT-SPI over D-Bus.

⇄ Desktop integration

Systemd and dinit units, D-Bus (freedesktop + GNOME/Mutter interfaces), portals, and Xwayland via Xwayland-satellite.

Built on Smithay, in Rust

ymir is written in Rust on top of the Smithay library, and drives output through an IPC server with a ymir msg CLI for full remote control. Three backends let you run it anywhere:

  • TTY — KMS/DRM on real hardware (udev + libseat + GBM)
  • Winit — windowed development mode inside a desktop
  • Headless — for the test suite

Try it in one line

The installer detects your distro, installs dependencies, and builds & installs ymir:

bash
curl -sL https://lab.braxton.onl/braxton/ymir/raw/branch/main/scripts/install.sh | bash

Or build it yourself:

sh
cargo build --release
Read the wiki Source & issues

Once inside: Super+T opens a terminal · Super+D a launcher · Super+Shift+E exits.
