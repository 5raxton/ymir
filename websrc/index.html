About

Windows are a quiet, ordered place.

Ymir arranges windows in columns on an infinite strip going to the right. It is built from the ground up for scrollable tiling, with dynamic workspaces, an overview, gestures, gradient borders, background blur, and live-reloading configuration.

Its Dwindle column mode layers a resizable binary tiling tree on top of that scrollable foundation — the best of both worlds.

  • Dynamic workspaces like in GNOME
  • An overview that zooms out workspaces and windows
  • Built-in screenshot UI and screencasting
  • Touchpad and mouse gestures
  • Group windows into tabs
  • Gradient borders with Oklab and Oklch
  • Background blur for windows and shell surfaces
  • Works with screen readers

Dwindle column mode

Binary tiling that behaves.

Windows split off the focused window into a resizable binary tree, Hyprland-style. Move the focused window with its spatial neighbor in any direction.

Split to fill

New windows split the focused node, so it keeps half its size and shrinks into its corner while the new window takes the freed half.

Move spatially

Mod+Shift+Left/Right swap the focused window with its spatial neighbor in the tree — no fullscreen surprises.

Switch anytime

Toggle between dwindle and classic scrollable tiling live with Mod+Shift+D.

Key bindings

Small, memorable defaults.

ModShiftLeftmove window left in the dwindle tree
ModShiftRightmove window right in the dwindle tree
ModCtrlUpmove window up in a column
ModCtrlDownmove window down in a column
ModShiftSpacetoggle split direction
ModShiftDswitch between dwindle and scrollable

Get started

Ymir is ready to tile.

Ymir builds with cargo and installs into /usr/local, or straight from the AUR/PKGBUILD on Arch. It seeds your config with the dwindle example and sets up a login-manager session for you. 

# Arch
makepkg -si

# or with Cargo
cargo install --path .
