About

Windows are a quiet, ordered place.

Ymir arranges windows in columns on an infinite strip going to the right. It is built for scrollable tiling and tiling layouts alike, with dynamic workspaces, an overview, gestures, gradient borders, background blur, and live-reloading Lua configuration.

Its Dwindle column mode layers a resizable binary tiling tree on top of that scrollable foundation — and it is on by default. A Depth mode turns a column into a deck of perspective-tilted cards with a full-size apex window.

  • Dynamic workspaces like in GNOME
  • An overview that zooms out workspaces and windows
  • Built-in screenshot UI and screencasting
  • Touchpad and mouse gestures
  • Group windows into tabs
  • Gradient borders with Oklab and Oklch
  • Depth: a deck-style queue with a full-size apex card
  • Per-workspace layout config, including numeric workspace tags
  • Works with screen readers

Column display modes

Tiling, scrollable, tabbed — or a depth queue.

Every column can switch between four display modes at runtime: dwindle (binary-split tree), scrollable, tabbed, and depth. Windows split off the focused window into a resizable binary tree; swap the focused window with its spatial neighbor, or flip the split orientation at any time.

Split to fill

New windows split the focused node, so it keeps half its size and shrinks into its corner while the new window takes the freed half.

Move spatially

Mod+Shift+Left/Right swap the focused window with its spatial neighbor in the tree — no fullscreen surprises.

Switch anytime

Cycle the focused column between dwindle, scrollable, tabbed and depth live with Mod+Shift+D.

Key bindings

Small, memorable defaults.

ModShiftLeftmove window left in the dwindle tree
ModShiftRightmove window right in the dwindle tree
ModCtrlUpmove window up in a column
ModCtrlDownmove window down in a column
ModSpaceflip the split orientation
ModCtrlSpacepreselect the next split's direction
ModShiftHomepromote the focused window to the head of the tree
ModShiftDcycle dwindle, scrollable, tabbed and depth

Get started

Ymir is ready to tile.

On Arch, Ymir builds with makepkg from the bundled PKGBUILD. On any distro, the installer detects it, installs dependencies, builds and installs into /usr/local. It seeds your config with the dwindle default and sets up a login-manager session entry for you. 

# Arch, at the repo root
makepkg -si

# or on any distro
curl -sL https://lab.braxton.onl/braxton/ymir/raw/branch/main/scripts/install.sh | bash
